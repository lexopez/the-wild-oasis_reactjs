# The Wild Oasis Admin App

A full-stack hotel management dashboard recreated from Jonas Schmedtmann’s React course. This application is designed for internal staff use and provides an admin interface for managing cabins, bookings, guests, settings, and hotel operations through a centralized dashboard.

> **Note**
> This project was recreated as part of a hands-on learning project by following Jonas Schmedtmann’s React course. It serves as a portfolio project demonstrating my understanding of building a production-style admin dashboard with React, authentication, CRUD workflows, charts, and data-driven UI patterns.

---

## Overview

The Wild Oasis Admin App is an internal hotel management system built for hotel staff and administrators. It allows authenticated users to manage reservations, cabins, guest records, and hotel settings from a protected dashboard.

The project focuses heavily on dashboard architecture, data fetching, reusable UI components, state management, filtering, charts, and admin-focused workflows commonly found in business management systems.

---

## Features

- Secure staff authentication
- Dashboard overview with booking and sales metrics
- Cabin management
- Booking management
- Guest management
- Hotel settings management
- Reservation status tracking
- Date-based filtering and statistics
- Check-in / check-out workflow
- Protected routes
- Data tables and sorting
- Charts and summary cards
- Dark and clean admin dashboard UI
- Reusable component-based architecture
